# 技能系统

## 与工具系统的区别

| | 工具 (Tool) | 技能 (Skill) |
|---|---|---|
| 状态 | 无状态，单次执行 | 有状态，支持多步骤循环 |
| 生命周期 | `execute()` 一次完成 | `start()` → `step()` × N → `stop()` |
| 返回 | 字符串 | `(SkillStatus, SkillContext)` |
| 用途 | 原子操作（计算、搜索） | 复杂能力（规划、探索） |

## 目录结构

```
src/skills/
├── __init__.py          # 导出 BaseSkill, SkillLoader, 类型
├── types.py             # SkillState, SkillStatus, SkillContext
├── base.py              # BaseSkill 抽象基类
├── loader.py            # SkillLoader 加载器
├── builtin/             # 内置技能
│   └── planner/         # 任务规划技能
└── custom/              # 用户自定义技能
```

## 核心概念

### SkillContext

每次 `step()` 调用之间传递的上下文，承载技能的运行状态：

```python
@dataclass
class SkillContext:
    skill_id: str          # 唯一标识
    task: str              # 原始任务目标
    steps: list[dict]      # 执行历史
    state: dict            # 技能内部状态（phase, plan_lines 等）
    metadata: dict         # 元数据
    created_at / updated_at
```

### SkillStatus（step 的返回值）

| 状态 | 含义 | 后续动作 |
|---|---|---|
| `CONTINUE` | 继续下一轮 step | agent 自动循环 |
| `DONE` | 技能执行完成 | 返回格式化结果 |
| `WAIT` | 等待 LLM 补充信息 | 返回当前结果，暂停 |
| `ERROR` | 不可恢复错误 | 返回错误信息 |

### 生命周期

```
start(task) → step() → step() → ... → DONE/WAIT
                 ↑                      ↓
              CONTINUE               stop(context)
```

`resume(context)` 用于从 WAIT 状态恢复，接收 LLM 的补充输入后继续 `step()`。

## 内置技能

### planner

将复杂目标分解为结构化计划，分 3 个阶段执行：

```
analyzing → planning → done
```

- **analyzing**：写入计划文件头部（时间戳、目标）
- **planning**：添加子任务列表，返回 `WAIT`（等待确认）
- **done**：输出完整计划内容到 `context.state["plan_content"]`

使用示例：

```python
planner = SkillLoader().get_skill("planner")
ctx = planner.start("实现用户登录功能")
while True:
    status, ctx = planner.step(ctx)
    if status == SkillStatus.DONE:
        print(ctx.state["plan_content"])
        break
```

## 与 Agent 集成

Agent 在 `run_with_tools()` 中将技能定义合并到 tools 列表，LLM 可像调用工具一样调用技能（`skill_planner`）。Agent 检测 `skill_` 前缀后路由到 `_handle_skill()` 执行循环。

```python
# Agent 自动处理，开发者只需定义 BaseSkill 子类
def handle_tool(tool_call):
    if tool_name.startswith("skill_"):
        return agent._handle_skill(tool_name, **tool_args)
    # ... 工具逻辑
```

## 创建自定义技能

在 `src/skills/custom/` 下创建技能目录：

```
src/skills/custom/my_skill/
└── skill.py
```

```python
from src.skills.base import BaseSkill
from src.skills.types import SkillContext, SkillStatus

class MySkill(BaseSkill):
    name = "my_skill"
    description = "自定义技能描述"
    skill_type = "custom"

    def step(self, context: SkillContext) -> tuple[SkillStatus, SkillContext]:
        # 多步骤逻辑
        if context.state.get("phase") == 0:
            context.state["phase"] = 1
            return SkillStatus.CONTINUE, context
        # ...
        return SkillStatus.DONE, context

skill = MySkill()
```

技能自动被加载，无需额外配置。
