# 技能系统

## 核心思路

Skill 是 md 文件定义的 prompt 片段，通过 frontmatter 实现**按需加载**：
- 启动时只解析 frontmatter 元数据，极少量 token
- LLM 决策后才加载完整内容
- 支持 `reference.md`、`examples.md` 按需追加

## 目录结构

```
src/skills/
├── loader.py             # SkillLoader（扫描 + frontmatter 解析 + 按需加载）
├── types.py              # Skill 数据类
├── builtin/              # 内置技能
│   └── planner/
│       └── README.md     # frontmatter + 技能指令
└── custom/               # 用户自定义技能
    └── code-review/
        ├── README.md
        ├── reference.md  # 可选：参考资料
        └── examples.md   # 可选：使用示例
```

## README.md 格式

```yaml
---
name: code-review
description: Systematic code review for quality and security
version: 2.0.0
author: FAN628978
triggers:
  - review
  - code review
  - check my code
  - PR review
  - 代码评审
allowed-tools:
  - calculator
  - web_search
---

# Code Review

## 角色
...
```

**frontmatter 字段说明：**

| 字段 | 必填 | 说明 |
|---|---|---|
| `name` | 是 | 技能唯一标识 |
| `description` | 是 | 简短描述（启动时加载到 prompt 列表） |
| `version` | 否 | 版本号，默认 1.0.0 |
| `triggers` | 否 | 触发词列表，检测到则自动激活技能 |
| `allowed-tools` | 否 | 该技能允许使用的工具列表 |
| `author` | 否 | 作者信息 |

## 执行流程（5 阶段）

```
Phase 1: 启动扫描
  SkillLoader.load_all()
  → _scan_directory() 扫描 skill 目录

Phase 2: 元数据加载（仅 frontmatter）
  每个 Skill 只读取：
    name / description / version / triggers / allowed-tools
  token 消耗：100个Skill × ~20 tokens ≈ 2000 tokens

Phase 3: 请求匹配
  用户输入 → 与 description / triggers 匹配
  → LLM 决策调用哪个 Skill

Phase 4: 按需加载完整内容
  SkillLoader.get_skill_prompt(name)
  → 读取 README.md（跳过 frontmatter）
  → 追加 reference.md（如果存在）
  → 追加 examples.md（如果存在）

Phase 5: 注入与执行
  → 完整 md 内容注入 system prompt
  → 预批准 allowed-tools 中的工具
  → LLM 按技能指令执行
```

## 与 Agent 集成

```python
# 1. 初始化时只加载列表（无完整内容）
agent = Agent(config)
# → available_skills: [{name, description, version}, ...]

# 2. 用户输入触发检测
agent.run_with_tools("请帮我 review 这段代码")
# → _check_skill_triggers 检测到 "review"
# → _activate_skill("code-review")
# → 将完整内容注入 messages 历史

# 3. 按需加载完整内容
skill_prompt = agent.skill_loader.get_skill_prompt("code-review")
# → 读取 README.md + reference.md + examples.md
```

## 创建自定义技能

```
src/skills/custom/my_skill/
├── README.md      # 必需：frontmatter + 技能指令
├── reference.md    # 可选：参考资料
└── examples.md     # 可选：使用示例
```

技能自动被加载，无需额外配置。
