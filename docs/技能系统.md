# 技能系统

## 与工具系统的区别

| | 工具 (Tool) | 技能 (Skill) |
|---|---|---|
| 定义方式 | Python 类，继承 `BaseTool` | Markdown 文件，`README.md` |
| 暴露方式 | 通过 function calling 暴露给 LLM | 注入到 system prompt，引导 LLM 行为 |
| 调用方式 | LLM 主动调用 `tool.execute()` | LLM 按照 skill 的 md 内容指导自身行为 |
| 状态 | 无状态，单次执行 | 无状态，通过 prompt 约束 LLM 行为 |

## 目录结构

```
src/skills/
├── loader.py            # SkillLoader 加载器
├── types.py             # Skill 数据类
├── builtin/             # 内置技能
│   └── planner/         # 任务规划技能
│       └── README.md
└── custom/              # 用户自定义技能
```

## 技能格式

技能是一个文件夹，文件夹名即为技能名称，文件夹内必须有 `README.md` 文件。

```
src/skills/custom/my_skill/
└── README.md
```

`README.md` 的第一行 `# 标题` 作为技能的简短描述，其余内容作为完整技能指令注入到 system prompt。

示例 `README.md`：

```markdown
# Planner

## 角色
你是一个专业的任务规划助手...

## 工作流程
1. 分析需求
2. 拆解任务
3. 输出计划
...
```

## 加载流程

```
SkillLoader.load_all()
  └── _scan_directory()       扫描 skill 目录
        └── _load_skill_from_path()
              ├── 读取 README.md
              ├── 第一行 #xxx → description
              └── 完整内容 → content
```

## 与 Agent 集成

Agent 在每次对话时调用 `_build_system_prompt()`，将所有技能 md 内容追加到 system prompt：

```
最终 system_prompt = 用户配置的 prompt

## 技能 (Skills)

## planner
# Planner
<skill content>

## another_skill
# Another
<another skill content>
```

LLM 会根据注入的技能指令指导自己的行为，无需显式调用。

## 创建自定义技能

在 `src/skills/custom/` 下创建技能目录：

```
src/skills/custom/web_research/
└── README.md
```

技能自动被加载，无需额外配置。
