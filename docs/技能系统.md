# 技能系统

## 核心思路

Skill 是 md 文件定义的 prompt 片段，通过 frontmatter 实现**按需加载**：
- 启动时只解析 frontmatter 元数据，极少量 token
- LLM 决策后才加载完整内容
- 支持 `reference.md`、`examples.md` 按需追加

## 目录结构

```
src/skills/
├── loader.py             # SkillLoader（扫描 + frontmatter 解析 + 按需加载）
├── types.py              # Skill 数据类
├── __init__.py
├── planner/              # 技能目录（目录名 = 技能名）
│   └── SKILL.md         # frontmatter + 技能指令
└── code-review/          # 另一个技能
    ├── SKILL.md
    ├── reference.md     # 可选：参考资料
    └── examples.md      # 可选：使用示例
```

## SKILL.md 格式

```yaml
---
name: code-review
description: Systematic code review for quality and security
version: 2.0.0
triggers:
  - review
  - code review
  - check my code
  - 代码评审
allowed-tools:
  - calculator
  - web_search
---

# Code Review

## 角色
你是一个资深代码评审专家...
```

**frontmatter 字段说明：**

| 字段 | 必填 | 说明 |
|---|---|---|
| `name` | 是 | 技能唯一标识（与目录名无关） |
| `description` | 是 | 简短描述 |
| `version` | 否 | 版本号，默认 1.0.0 |
| `triggers` | 否 | 触发词列表 |
| `allowed-tools` | 否 | 该技能允许使用的工具 |

## 执行流程（5 阶段）

```
Phase 1: Agent 初始化
  SkillLoader.load(custom_skills_path)
  → 扫描 src/skills/ 下的所有子目录
  → _load_frontmatter() 只读取 SKILL.md 的 frontmatter
  → Skill 对象存入 _skills 字典（content 为空）

Phase 2: 构建启动 prompt
  _build_system_prompt()
  → ## 可用技能 (Skills)
  → - planner (1.0.0): 任务规划专家... 触发: planner, 制定计划...
  → - code-review (2.0.0): Systematic code review... 触发: review, 代码评审...
  token 消耗极少

Phase 3: 用户输入匹配
  _check_skill_triggers(user_input)
  → 优先匹配 triggers 字段
  → 兜底：skill 名称分词匹配

Phase 4: 按需加载完整内容
  _activate_skill(name)
  → get_skill_prompt(name)
  → 读取 SKILL.md（跳过 frontmatter）
  → 追加 reference.md（如果存在）
  → 追加 examples.md（如果存在）

Phase 5: 注入并执行
  → 完整 md 内容注入 messages 历史（role=system）
  → LLM 按技能指令执行
```

## 与 Agent 集成

```python
# 1. 初始化时只加载列表
agent = Agent(config)
# → available_skills: [{name, description, version, triggers}, ...]

# 2. 用户输入触发自动激活
await agent.run_with_tools("帮我 review 代码")
# → 检测到 "review" → 激活 code-review
# → 完整内容注入 messages

# 3. 按需加载完整内容
skill_prompt = agent.skill_loader.get_skill_prompt("code-review")
# → 读取 SKILL.md + reference.md + examples.md
```

## 创建自定义技能

```
src/skills/custom/my_skill/
├── SKILL.md       # 必需：frontmatter + 技能指令
├── reference.md    # 可选：参考资料
└── examples.md     # 可选：使用示例
```

通过 `AgentConfig(custom_skills_path=Path("..."))` 指定额外扫描目录。
