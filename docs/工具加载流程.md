# 工具加载流程

## 一、核心文件

| 文件 | 作用 |
|---|---|
| `src/tools/base.py` | 抽象基类 `BaseTool`，定义工具规范 |
| `src/tools/loader.py` | 核心加载器 `ToolLoader`，负责扫描目录、动态加载工具 |
| `src/agent/agent.py` | Agent 主类，持有 `ToolLoader`，在对话中调度工具 |
| `src/agent/client.py` | OpenAI API 封装，处理 LLM 调用循环 |

---

## 二、工具数据结构

每个工具继承 `BaseTool`，只需定义三个部分：

```python
class CalculatorTool(BaseTool):
    name = "calculator"
    description = "执行数学表达式计算"

    def execute(self, expression: str) -> str:
        return str(result)

tool = CalculatorTool()  # 必须在模块级实例化！
```

关键约定：**每个 `tool.py` 必须导出名为 `tool` 的实例**，这是加载机制的核心依赖。

---

## 三、加载流程

`ToolLoader` 使用 `importlib.util` 动态导入，不依赖 `import` 语句：

```
load_all()
  ├── load_builtin()      # 扫描 src/tools/builtin/ 下的子目录
  │     └── _scan_directory() → _load_tool_from_path()
  └── load_custom()       # 扫描 src/tools/custom/，追加到 _tools 字典
        └── _scan_directory() → _load_tool_from_path()
```

核心逻辑在 `_load_tool_from_path` 中：

```python
# 构造模块名: src.tools.builtin.calculator.tool
module_name = f"src.tools.{tool_dir.parent.name}.{tool_dir.name}.tool"
spec = importlib.util.spec_from_file_location(module_name, tool_file)
module = importlib.util.module_from_spec(spec)
spec.loader.exec_module(module)
return module.tool  # 获取模块级的 tool 实例
```

这是一种**约定优于配置**的设计——通过目录结构和 module 级变量来发现工具，无需显式注册。

## 四、工具调用执行链

```
用户输入
  │
  ▼
Agent.run_with_tools(user_input)
  │
  ▼
OpenAIClient.chat_with_tools(
    messages,
    tools=tool_loader.get_definitions(),  # 传给 LLM 的工具 schema
    tool_handler=handle_tool
)
  │
  ▼  LLM 判断是否调用工具
  ├── 无 tool_calls → 直接返回文本
  └── 有 tool_calls → 循环处理
         │
         ▼
      handle_tool(tool_call)
         ├── json.loads(tool_call.function.arguments)
         ├── tool_loader.get_tool(name)     # 从字典查找
         ├── tool.execute(**args)           # 执行
         └── 返回结果字符串，加入 messages
         │
         ▼  继续发请求给 LLM，直到不再调用工具
```

---

## 五、设计特点

1. **内置 vs 自定义优先级** — `load_all()` 先清空内置再追加自定义，同名时自定义覆盖内置
2. **工具参数定义为空** — `get_definition()` 目前返回固定空 `parameters`，LLM 依赖 `description` 推断参数
3. **无结构化返回** — `execute()` 直接返回 `str`，没有 JSON schema 或类型校验
4. **当前内置工具** — `calculator`（白名单安全 eval）、`web_search`（爬取 Bing）
